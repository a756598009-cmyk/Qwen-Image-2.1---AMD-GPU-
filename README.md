# Qwen-Image-2.1 Uncensored GGUF --- AMD RX 7900 XTX / Windows 11

本教程整理 **Windows 11 + AMD Radeon RX 7900 XTX 24GB + ComfyUI Windows
Portable AMD** 的本地部署流程。

## 1. 环境

  项目           配置
  -------------- ---------------------------------------
  GPU            AMD Radeon RX 7900 XTX 24GB
  RAM            32GB
  OS             Windows 11
  ComfyUI        Windows Portable AMD
  Diffusion      `qwen-image-2.1-Q4_K_M.gguf`
  Text Encoder   `qwen3vl_8b_int8_convrot.safetensors`
  VAE            `qwen_image_2.1_vae_bf16.safetensors`
  GGUF Node      `leejet/ComfyUI-GGUF`

本教程针对 AMD GPU，不需要 NVIDIA CUDA 环境。

## 2. 下载 ComfyUI AMD 便携版

官方 AMD Portable：

[下载 ComfyUI Windows Portable
AMD](https://github.com/Comfy-Org/ComfyUI/releases/latest/download/ComfyUI_windows_portable_amd.7z)

解压后目录：

``` text
ComfyUI_windows_portable_amd/
├── ComfyUI/
├── python_embeded/
├── update/
├── README_VERY_IMPORTANT.txt
└── run_amd_gpu.bat
```

例如放在：

``` text
C:\Image2.1\ComfyUI_windows_portable_amd\ComfyUI_windows_portable
```

官方 AMD Portable 使用 `run_amd_gpu.bat` 启动。

## 3. 安装 ComfyUI-GGUF

使用维护的 Qwen Image 2.1 支持版本：

[leejet/ComfyUI-GGUF](https://github.com/leejet/ComfyUI-GGUF)

在 Portable 根目录执行：

``` bat
git clone https://github.com/leejet/ComfyUI-GGUF ComfyUI\custom_nodes\ComfyUI-GGUF
```

安装依赖：

``` bat
.\python_embeded\python.exe -s -m pip install -r .\ComfyUI\custom_nodes\ComfyUI-GGUF\requirements.txt
```
